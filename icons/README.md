# アイコンの作成方法

この拡張機能にはアイコンが必要です。以下のいずれかの方法でアイコンを作成してください。

## 方法1: SVGからPNGに変換

1. `icons/icon16.svg` を参考にアイコンを作成
2. 画像編集ソフトで以下のサイズのPNGに変換：
   - `icon16.png` (16x16ピクセル)
   - `icon48.png` (48x48ピクセル)
   - `icon128.png` (128x128ピクセル)

## 方法2: オンラインツールを使用

- [Favicon Generator](https://favicon.io/favicon-generator/) などのツールを使用
- YouTubeのロゴや関連するアイコンを使用

## 方法3: シンプルなアイコンを作成

- 赤色背景に白い再生ボタン（▶）のアイコン
- または「YT」などのテキストベースのアイコン

## 注意

アイコンが設定されていない場合でも、拡張機能は正常に動作しますが、Chromeの拡張機能マネージャーでアイコンが表示されません。
