# YouTube書き起こしダウンロード Chrome拡張機能

YouTube動画の書き起こしをプレーンテキスト形式でダウンロードできるChrome拡張機能です。

## 機能

- YouTubeのデフォルトの文字起こし機能を使用して文字起こしをダウンロード
- プレーンテキスト形式で保存
- 動画タイトルをファイル名に使用
- **ヘッダーにアイコンボタンを配置** - 右上のヘッダーにダウンロードアイコンが表示されます
- **自動的に文字起こしパネルを開く** - ボタンをクリックするだけで文字起こしパネルが自動的に開きます
- **テキストファイルの最後にURLを追加** - ダウンロードしたファイルの最後に動画のURLが追加されます
- **自動整形機能**:
  - 重複テキストの除去（同じ文章が3回繰り返されている場合は1回に整理）
  - UI要素の除去（「オープニング」「[音楽]」「タップして再試行」など）
  - セクションヘッダーの除去
  - 短い繰り返しの除去（「うん。うん。うん。」→「うん。」など）
  - 適切な改行の追加（読みやすい形式に整形）

## インストール方法

### ステップ1: Chrome拡張機能ページを開く
1. Chromeブラウザを開く
2. アドレスバーに `chrome://extensions/` と入力してEnterを押す
   - または、右上の三点メニュー → 「拡張機能」 → 「拡張機能を管理」

### ステップ2: デベロッパーモードを有効にする
1. 拡張機能ページの右上にある「デベロッパーモード」のトグルをONにする

### ステップ3: 拡張機能を読み込む
1. 画面上部に表示される「パッケージ化されていない拡張機能を読み込む」ボタンをクリック
2. ファイル選択ダイアログが開くので、このプロジェクトのディレクトリ（`youtube_transcript_downloader`）を選択
3. 拡張機能が読み込まれ、リストに表示されます

### インストール完了後の確認
- 拡張機能がリストに表示され、エラーがなければインストール成功です
- YouTubeの動画ページを開くと、ヘッダー右上にダウンロードアイコンが表示されます

## アイコンの設定

拡張機能のアイコンを設定するには、`icons/` ディレクトリに以下のサイズのPNG画像を配置してください：

- `icon16.png` (16x16ピクセル)
- `icon48.png` (48x48ピクセル)
- `icon128.png` (128x128ピクセル)

アイコンが設定されていない場合でも、拡張機能は動作します。

## 使用方法

### 基本的な使い方
1. **YouTubeで動画を開く**
   - ブラウザでYouTubeの動画ページ（例: `https://www.youtube.com/watch?v=xxxxx`）を開く

2. **ヘッダーのアイコンボタンを確認**
   - ページの右上、ヘッダー部分にダウンロードアイコンが表示されます
   - アイコンにマウスをホバーすると「文字起こしをダウンロード」というツールチップが表示されます

3. **アイコンボタンをクリック**
   - ヘッダーのダウンロードアイコンをクリック
   - 自動的に文字起こしパネルが開き、文字起こしが取得されます
   - 数秒後にダウンロードが開始されます

4. **ダウンロード完了**
   - 文字起こしがテキストファイル（`.txt`）としてダウンロードされます
   - ファイル名は「動画タイトル_transcript.txt」の形式です
   - ファイルの最後に動画のURLが追加されます

### トラブルシューティング
- **アイコンボタンが表示されない場合**
  - 動画ページ（`/watch`で始まるURL）にいることを確認してください
  - ページをリロードしてみてください
  - `chrome://extensions/` で拡張機能が有効になっているか確認してください
  - ブラウザのコンソール（F12キー）でエラーメッセージを確認してください

- **文字起こしがダウンロードできない場合**
  - 動画に文字起こしが存在することを確認してください（自動生成されていない動画にはダウンロードできません）
  - 文字起こしパネルが開いているか確認してください（手動で「文字起こしを表示」ボタンをクリックして開くこともできます）
  - 動画ページをリロードしてみてください

- **拡張機能が動作しない場合**
  - `chrome://extensions/` で拡張機能が有効になっているか確認してください
  - エラーが表示されている場合は、詳細を確認してください
  - ブラウザのコンソール（F12キー）でエラーを確認してください

## 注意事項

- 文字起こしが存在しない動画にはダウンロードできません
- YouTubeのUIの仕様変更により動作しなくなる可能性があります
- 個人利用のみを想定しています
- ダウンロードしたテキストファイルの最後に動画のURLが追加されます

## 技術的な詳細

- Manifest V3形式を使用
- YouTubeのデフォルトの文字起こしパネルからテキストを取得
- コンテンツスクリプトでYouTubeページのヘッダーにアイコンボタンを追加
- DOM操作で文字起こしパネルの内容を抽出
- **文字起こしパネルの自動展開**:
  - `ytd-video-description-transcript-section-renderer`内の「文字起こしを表示」ボタンを検出して自動的にクリック
  - フォールバックとして「…」メニューからも開くことを試行
- **テキスト整形処理**:
  - 改行単位での重複検出（長い文章の重複を検出）
  - 語単位での重複検出（100語〜5語のパターンで検出）
  - 文単位での重複検出（句読点で分割して検出）
  - UI要素やタイムスタンプの自動除去
  - セクションヘッダーの自動除去
  - 句読点の前後の空白整理
  - 文の終わりでの自動改行追加
- **ファイル形式**:
  - プレーンテキスト形式（`.txt`）
  - ファイルの最後に動画のURLを追加（区切り線付き）
